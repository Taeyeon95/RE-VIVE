═══ 문제 정의 ═══
한 줄 소개: 금연 중 흡연 충동을 즉각적인 운동과 목표 보상 시스템으로 극복하는 금연 유지 앱
해결하려는 문제: 금연을 시도하는 성인 흡연자들이 니코틴 중독과 스트레스로 인한 흡연 충동을 이겨내지 못하고 금연을 중도 포기하는 문제
배경 및 필요성: 흡연은 니코틴 중독뿐 아니라 스트레스 해소의 보상 심리와 결합되어 금연 유지가 매우 어렵다. 특히 직장인 등 일상 속에서 충동이 찾아올 때 즉각적으로 대처할 수 있는 수단이 없어 결국 다시 담배에 손을 뻗게 된다. 기존 금연 앱은 절약 금액 표시 등 장기적 동기부여 위주로 충동이 오는 바로 그 순간을 효과적으로 버티게 해주는 기능이 부족하다.

기능 개요:
바탕화면 위젯을 통해 충동 발생 즉시 접근하고, 사용자가 미리 선택한 간단한 운동(나이·신체 조건 기반 추천 포함)으로 1~2분을 버티면, 사용자가 설정한 목표 물건의 달성 퍼센트가 채워지는 보상 시스템을 제공한다. 위젯은 평소엔 심플하게 표시되다가 누를 때만 목표 물건 사진과 퍼센트가 보여 사생활을 보호하며, 설정에서 글씨 크기 및 화면 단순화 옵션을 제공해 다양한 연령대가 사용할 수 있다.

═══ 이해관계자 분석 ═══
▸ 직장인 흡연자 (주요 사용자, 20~40대)
  현재 불편함: 금연을 시도하고 있지만 업무 스트레스를 받을 때마다 흡연 충동이 찾아와 중간에 포기하는 경우가 많다. 회사에서 담배를 피우러 자리를 비우는 것에 눈치를 느끼기도 한다.
  SW 사용 목적: 자리에서 벗어나지 않고 눈치 보지 않으면서 1~2분 안에 흡연 충동을 해소하고 싶다. 목표 물건을 사기 위해 담배값을 모으는 현실적인 동기부여 방식으로 금연을 유지하고자 한다.
  SW와의 관계: 금연 앱의 핵심 사용자로, 충동 해소 기능과 목표 물건 퍼센트 채우기 기능을 주로 활용한다.

▸ 중장년 흡연자 (주요 사용자, 50~60대)
  현재 불편함: 금연 의지는 있지만 신체 조건상 격한 운동이 어렵고, 스마트폰 앱 조작이 익숙하지 않아 복잡한 UI에서 어려움을 느낀다.
  SW 사용 목적: 건강을 위해 금연을 유지하고 싶으며, 자신의 신체 조건에 맞는 가벼운 운동으로 충동을 해소하길 원한다. 글씨 크기 조절 등 접근성 설정을 통해 앱을 편리하게 사용하고자 한다.
  SW와의 관계: 연령과 신체 조건에 맞는 운동 추천 기능 및 접근성 설정의 필요성을 만들어낸 사용자 그룹이다.

▸ 간접흡연 피해자 (이해관계자, 전 연령)
  현재 불편함: 주변 흡연자로 인해 간접흡연 피해를 자주 겪으며, 흡연자가 담배를 끊어주기를 바라지만 직접적으로 강요하기 어려운 상황이다.
  SW 사용 목적: 주변 흡연자가 자발적으로 금연에 성공하기를 바라며, 이 앱이 흡연자의 금연 유지를 도와 간접흡연 피해가 줄어들기를 기대한다.
  SW와의 관계: 앱 개발의 근본적인 동기가 된 존재로, 흡연자의 금연 성공으로 직접적인 혜택을 받는 이해관계자이다.

▸ 앱 개발자 및 운영자 (운영자, 20~30대)
  현재 불편함: 금연 앱의 기획, 개발, 유지보수를 담당하며 사용자 데이터를 관리하고 운동 콘텐츠 및 목표 달성 시스템을 운영해야 하는 부담이 있다.
  SW 사용 목적: 사용자들이 금연에 성공할 수 있도록 앱의 기능을 지속적으로 개선하고, 연령별 맞춤 운동 추천 알고리즘과 위젯 기능을 안정적으로 제공하고자 한다.
  SW와의 관계: 앱의 핵심 기능인 충동 해소 운동, 목표 물건 퍼센트 채우기, 바탕화면 위젯을 설계하고 운영하는 주체이다.

═══ 기능 설계 ═══
[ 기능 1: 흡연 충동 즉시 해소 운동 가이드 ]
기능 설명: 흡연 충동이 느껴지는 순간, 사용자가 미리 선택해둔 간단한 운동(손 스트레칭, 호흡법 등)을 1~2분간 안내하여 충동을 해소시켜주는 기능. 나이와 신체 조건을 입력하면 맞춤 운동을 추천해준다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 사용자가 처음 앱을 시작할 때 나이와 신체 조건(예: 무릎 불편, 허리 약함 등)을 선택해요. 이 정보를 바탕으로 나중에 맞춤 운동을 추천해줄 거예요.
    입력 데이터: 나이, 신체 조건 정보
  단계 2 (시스템 처리) — 앱이 입력된 나이와 신체 조건을 분석해서, 이 사람에게 맞는 간단한 운동 목록(예: 손 스트레칭, 호흡법, 어깨 돌리기 등)을 골라줘요.
    출력/결과: 맞춤 운동 추천 목록
  단계 3 (사용자 입력) — 추천된 운동 목록 중에서 사용자가 자신이 하고 싶은 운동을 직접 골라요. 고른 운동은 나중에 충동이 올 때 바로 안내해줄 기본 운동으로 저장돼요.
    입력 데이터: 선택한 운동 종류
    출력/결과: 선택 완료 저장
  단계 4 (결과 출력) — 흡연 충동이 느껴져 위젯을 누르면, 사용자가 미리 골라둔 운동을 1~2분 동안 단계별로 화면에 안내해줘요. 자리에서 조용히 할 수 있어 눈치 보지 않아도 돼요.
    출력/결과: 운동 단계별 안내 화면
  단계 5 (조건 분기) — 운동을 끝까지 완료했으면 목표 물건 퍼센트를 채워주고, 중간에 그만뒀으면 퍼센트는 채워지지 않고 '다시 도전해봐요!' 메시지를 보여줘요.
    출력/결과: 완료 시 퍼센트 증가 / 미완료 시 재도전 안내 메시지

[ 기능 2: 목표 물건 달성률 채우기 ]
기능 설명: 사용자가 갖고 싶은 물건을 등록해두면, 담배 충동을 버틸 때마다 절약된 금액만큼 목표 물건의 달성 퍼센트가 채워지는 현실적인 동기부여 기능.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 사용자가 앱에서 갖고 싶은 목표 물건(예: 에어팟, 운동화)과 가격을 직접 입력하고 사진도 등록해요.
    입력 데이터: 목표 물건 이름, 목표 금액, 물건 사진
  단계 2 (사용자 입력) — 담배 충동이 생겼을 때 바탕화면 위젯을 눌러서 '충동 버팀' 버튼을 눌러요. 이 순간부터 절약 금액 계산이 시작돼요.
    입력 데이터: 충동 버팀 버튼 클릭
  단계 3 (시스템 처리) — 앱이 담배 한 개비 평균 가격을 기준으로 이번에 절약된 금액을 계산하고, 목표 물건 가격 대비 몇 퍼센트가 채워졌는지 계산해요.
    입력 데이터: 누적 절약 금액, 목표 물건 가격
    출력/결과: 새로운 달성 퍼센트
  단계 4 (결과 출력) — 위젯을 누르면 목표 물건 사진과 함께 '67% 달성!' 처럼 퍼센트가 채워지는 화면이 보여요. 평소엔 심플하게 보여서 다른 사람이 봐도 금연 앱인지 알 수 없어요.
    출력/결과: 목표 물건 사진, 달성 퍼센트 바, 누적 절약 금액
  단계 5 (조건 분기) — 달성률이 100%가 되면 '목표 달성! 이제 살 수 있어요!' 축하 메시지가 뜨고, 아직 100%가 안 됐으면 '조금만 더 버텨봐요!' 응원 메시지가 표시돼요.
    입력 데이터: 현재 달성 퍼센트
    출력/결과: 100% 달성 시 축하 화면 또는 응원 메시지

[ 기능 3: 사생활 보호 바탕화면 위젯 ]
기능 설명: 평소에는 심플한 디자인으로 표시되다가, 사용자가 직접 누를 때만 목표 물건 사진과 달성률이 표시되는 홈 화면 위젯. 타인에게 금연 사실을 노출하지 않고 빠르게 앱 기능에 접근할 수 있다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 사용자가 홈 화면(바탕화면)에 있는 위젯을 손가락으로 탭(터치)해요. 평소에는 심플한 디자인으로 보여서 다른 사람이 봐도 금연 앱인지 알 수 없어요.
    입력 데이터: 위젯 터치 입력
  단계 2 (조건 분기) — 앱이 위젯을 누른 사람이 본인인지 확인해요. 만약 잠금이 풀린 상태(본인 확인 완료)라면 목표 물건 정보를 보여주고, 잠금 상태라면 잠금 해제를 먼저 요청해요.
    입력 데이터: 기기 잠금 해제 여부
    출력/결과: 잠금 해제 완료 / 잠금 해제 요청 화면
  단계 3 (데이터 조회) — 앱이 사용자가 미리 설정해둔 목표 물건 정보(사진, 목표 금액)와 지금까지 담배를 참아서 모은 금액을 불러와요.
    입력 데이터: 목표 물건 사진, 목표 금액, 현재 절약 금액
  단계 4 (결과 출력) — 위젯 화면이 바뀌면서 목표 물건 사진과 함께 현재 달성률(예: 67%)이 표시돼요. 사용자가 손을 떼거나 다른 곳을 터치하면 다시 심플한 화면으로 돌아가요.
    출력/결과: 목표 물건 사진 + 달성률 퍼센트 (예: 에어팟 67%)
  단계 5 (오류 처리) — 만약 사용자가 아직 목표 물건을 설정하지 않았다면, 위젯을 눌렀을 때 '목표 물건을 먼저 설정해보세요!' 라는 안내 메시지와 함께 설정 화면으로 이동하는 버튼이 나타나요.
    출력/결과: 목표 미설정 안내 메시지 + 설정 화면 이동 버튼

[ 기능 4: 연령·신체 맞춤 접근성 설정 ]
기능 설명: 나이와 신체 조건에 따라 적합한 운동을 추천하고, 글씨 크기 및 화면 단순화 등 UI 옵션을 설정에서 조정할 수 있어 고령 사용자도 불편 없이 사용할 수 있도록 지원하는 기능.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 처음 앱을 설치하면 나이와 몸 상태(예: 무릎이 안 좋음, 허리 통증 등)를 입력해요. 또 설정 화면에서 글씨 크기나 화면 단순화 여부를 직접 골라요.
    입력 데이터: 나이, 신체 조건(불편한 부위), 글씨 크기 설정, 화면 단순화 여부
  단계 2 (시스템 처리) — 앱이 입력된 나이와 신체 조건을 분석해서, 그 사람이 무리 없이 할 수 있는 운동 목록을 자동으로 골라줘요. 예를 들어 무릎이 불편한 어르신에게는 앉아서 하는 손 스트레칭만 추천해요.
    입력 데이터: 나이, 신체 조건
    출력/결과: 맞춤 추천 운동 목록
  단계 3 (결과 출력) — 추천된 운동 목록이 화면에 나타나고, 사용자가 그 중 마음에 드는 운동을 직접 골라 저장해요. 설정한 글씨 크기와 화면 스타일도 바로 적용돼서 화면이 바뀌어요.
    출력/결과: 맞춤 운동 선택 목록, 적용된 UI 화면(큰 글씨·단순 화면 등)
  단계 4 (오류 처리) — 나이나 신체 조건을 입력하지 않고 넘어가려 하면, '운동 추천을 위해 간단한 정보가 필요해요!'라는 안내 메시지가 떠서 꼭 입력하도록 도와줘요.
    출력/결과: 안내 메시지: '운동 추천을 위해 간단한 정보가 필요해요!'

[ 기능 5: 금연 동기 리마인더 ]
기능 설명: 사용자가 금연을 결심한 이유를 미리 입력해두면, 흡연 충동이 오는 순간 해당 이유를 화면에 띄워 긍정적인 생각으로 전환시켜주는 기능. 간접흡연 피해 감소, 건강 개선 등 개인별 동기를 기반으로 맞춤 메시지를 제공한다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 사용자가 앱에 처음 가입할 때, 자신이 담배를 끊으려는 이유를 직접 입력해요. 예를 들어 '가족 건강을 위해', '돈을 아끼려고' 같은 내용을 적는 거예요.
    입력 데이터: 금연 결심 이유 텍스트 (예: 아이 앞에서 담배 피우기 싫어서)
    출력/결과: 금연 동기 입력 완료
  단계 2 (시스템 처리) — 앱이 사용자가 입력한 금연 이유를 저장하고, 흡연 충동이 자주 오는 시간대나 상황을 분석해서 언제 메시지를 보여줄지 준비해요.
    입력 데이터: 저장된 금연 동기 텍스트, 사용자 충동 기록 데이터
    출력/결과: 맞춤 동기 메시지 생성 완료
  단계 3 (결과 출력) — 사용자가 바탕화면 위젯을 눌러 충동을 신고하면, 앱이 사용자가 입력해둔 금연 이유를 화면 가득 크게 보여줘요. 예를 들어 '당신이 담배를 끊으려는 이유: 아이 앞에서 담배 피우기 싫어서' 같은 메시지가 뜨는 거예요.
    출력/결과: 개인 맞춤 금연 동기 메시지 화면 표시
  단계 4 (조건 분기) — 메시지를 본 사용자가 '충동을 참았어요' 버튼을 누르면 목표 물건 퍼센트가 올라가고, 만약 아무 반응이 없으면 앱은 조용히 대기 상태로 돌아가요.
    입력 데이터: 사용자 버튼 선택 (참았음 / 무응답)
    출력/결과: 목표 물건 달성 퍼센트 증가 또는 대기 상태 유지

[ 기능 6: 금연 누적 통계 대시보드 ]
기능 설명: 금연을 시작한 날부터 현재까지 참은 횟수, 절약한 총 금액, 목표 물건 달성 이력 등을 한눈에 볼 수 있는 통계 화면. 사용자가 자신의 금연 여정을 돌아보며 꾸준히 동기를 유지할 수 있도록 돕는다.

  [ 처리 단계 ]
  단계 1 (사용자 입력) — 사용자가 대시보드 화면을 열어요. 화면 하단 메뉴에서 '내 기록' 또는 '통계' 버튼을 탭해요.
    입력 데이터: 사용자 탭 동작 (대시보드 메뉴 버튼)
  단계 2 (데이터 조회) — 앱이 지금까지 저장된 금연 기록을 불러와요. 금연 시작일, 충동을 참은 횟수, 매번 절약된 담배값, 목표 물건 달성 이력 등을 모두 가져와요.
    입력 데이터: 사용자 ID, 금연 시작일
    출력/결과: 참은 횟수 목록, 날짜별 절약 금액, 목표 물건 달성 기록
  단계 3 (시스템 처리) — 불러온 기록을 바탕으로 총 절약 금액, 총 참은 횟수, 목표 물건 달성 개수, 금연 유지 일수 등을 계산해요.
    입력 데이터: 날짜별 절약 금액 목록, 충동 참은 횟수 목록
    출력/결과: 총 절약 금액, 총 참은 횟수, 금연 유지 일수, 달성한 목표 물건 수
  단계 4 (결과 출력) — 계산된 결과를 한눈에 보기 좋게 화면에 보여줘요. 금연 시작일부터 오늘까지의 여정, 절약한 돈 그래프, 달성한 목표 물건 이미지 등이 깔끔하게 표시돼요.
    출력/결과: 금연 유지 일수, 총 참은 횟수, 총 절약 금액 그래프, 달성 목표 물건 갤러리

기획서 내용 (아래 형식으로 작성):

[배경 및 필요성]
흡연 인구의 증가로 인해 비흡연자들의 간접흡연 피해가 심각한 사회적 문제로 대두되고 있다. 특히 금연을 시도하는 흡연자들의 경우, 니코틴 중독성과 스트레스 상황에서의 습관적 흡연으로 인해 금연 유지에 큰 어려움을 겪고 있다. 기존 금연 앱들은 단순한 금연 일수 기록이나 절약 금액 표시 등 뻔한 기능에 그쳐 실질적인 충동 억제 효과가 부족하다는 한계가 있다. 이에 흡연 충동이 발생하는 순간을 효과적으로 극복할 수 있도록 돕는 실용적인 금연 보조 애플리케이션의 개발이 필요하다.

[해결 방안]
본 앱은 금연 중인 사용자가 흡연 충동을 느끼는 순간, 즉각적이고 현실적인 방법으로 충동을 해소할 수 있도록 지원한다. 핵심 해결 전략은 두 가지다. 첫째, 신체 활동을 통한 충동 해소로, 사용자가 사전에 선택한 간단한 운동을 1~2분간 수행하여 흡연 충동을 신체적으로 분산시킨다. 둘째, 목표 기반 보상 시스템으로, 담배를 참을 때마다 사용자가 원하는 물건의 구매 달성률이 채워지는 시각적 동기부여를 제공한다. 이 두 가지를 연계하여 충동을 버틴 직후 즉각적인 보상을 체감할 수 있도록 설계한다.

[주요 기능]
1. 바탕화면 위젯
- 스마트폰 홈 화면에 위젯을 상시 표시하여 앱을 실행하지 않아도 즉시 접근 가능
- 평소에는 심플한 디자인으로 표시되어 타인에게 금연 앱 사용 여부가 노출되지 않음
- 위젯을 누를 때만 목표 물건 이미지와 달성 퍼센트가 표시되어 사생활 보호

2. 맞춤형 간단 운동 기능
- 충동 발생 시 사용자가 사전에 선택한 간단한 운동(손 스트레칭, 호흡법, 가벼운 동작 등)을 1~2분간 안내
- 직장, 공공장소 등 어디서든 눈치 보지 않고 수행 가능한 운동 위주로 구성
- 운동 종류는 사용자가 자유롭게 선택 가능하며, 나이 및 신체 조건 입력 시 적합한 운동을 추천하여 고령 사용자도 무리 없이 활용 가능

- 단순 금액 숫자가 아닌 목표 물건 이미지와 퍼센트로 표현하여 동기부여 효과 극대화
- 운동 완료 시 달성률이 즉시 업데이트되어 행동과 보상이 즉각 연결됨

4. 접근성 설정
- 설정 메뉴에서 글씨 크기, 화면 단순화 등 옵션 제공
- 고령 사용자를 포함한 다양한 연령대가 불편함 없이 사용 가능하도록 UI 커스터마이징 지원

[기대 효과]

- 목표 물건 달성률이라는 현실적이고 직관적인 보상 시스템으로 성인 사용자에게도 유치하지 않은 동기부여 제공

- 나이 및 신체 조건 맞춤 운동 추천으로 고령자를 포함한 폭넓은 연령층이 활용 가능
- 장기적으로 흡연 인구 감소 및 간접흡연 피해 완화에 기여
